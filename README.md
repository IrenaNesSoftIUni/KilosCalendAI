# KilosCalendAI

Приложението е разделено на статичен frontend в `public/` и Express backend в
`server.js`. Backend-ът пази двата профила на всеки акаунт в SQLite и ограничава
достъпа до данните чрез удостоверена сървърна сесия.

## Стартиране локално

1. Инсталирай Node.js 20 или по-нова версия.
2. Изпълни `npm install`.
3. Копирай `.env.example` в `.env` и задай уникална стойност на
   `SESSION_SECRET` с дължина поне 32 символа.
4. Изпълни `npm start` и отвори `http://127.0.0.1:3000`.

По подразбиране SQLite базата се създава в `data/tracker.sqlite`. Пази базата
и `.env` като лични данни и добави базата към плана си за резервни копия.

## Публикуване

Използвай HTTPS в продукционна среда. Задай `NODE_ENV=production`, силен
`SESSION_SECRET` и `TRUST_PROXY=1` само ако приложението е зад доверен HTTPS
reverse proxy. При нужда задай `HOST` и `DATABASE_PATH` според хостинга. Не
публикувай SQLite файла или `.env` като статични файлове.
